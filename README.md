 # nixie-shell
A barebones shell made in C built for linux based operating systems

(yes, the commands are hardcoded (for now) because its a lot simpler and my main goal now is to simply understand new things like fork(), execvp(), PIDs, etc. instead of building something phenomenal)

Can currently execute the following commands:

ls, fastfetch, neofetch, clear, cd, pwd, help
